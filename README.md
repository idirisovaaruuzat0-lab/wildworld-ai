# WILDWORLD AI — AI for Life

WILDWORLD AI is a bilingual (Russian/English) personal planning app with two visual worlds: Jungle and Arctic. It helps users organize tasks, deadlines and available time into a daily schedule.

## Requirements
- Node.js 18 or newer
- Internet connection for Gemini AI
- A Gemini API key for real model-powered planning

## Run locally
1. Extract the ZIP.
2. Open the `wildworld-ai` folder in VS Code.
3. Open Terminal in that folder.
4. Install dependencies:
   ```bash
   npm install
   ```
5. Copy `.env.example` to `.env`.
6. Add your Gemini key to `.env`:
   ```env
   GEMINI_API_KEY=your_key_here
   PORT=3000
   ```
7. Start the server:
   ```bash
   npm start
   ```
8. Open http://localhost:3000

For development with automatic server restart: `npm run dev`.

## AI integration and security
The browser sends planning data to the local Express server at `POST /api/plan`. The server calls Google Gemini using the key in the environment. The key is never placed in `public/app.js` and must not be committed to Git. If no key is configured, the app clearly reports this and displays a labelled **DEMO MODE** schedule generated by a local heuristic. Demo mode is not represented as AI.

The server currently uses `gemini-2.5-flash`. If this model is unavailable to your account or region, change the model identifier in `server/index.js` to a currently enabled Gemini model.

## Features
- Jungle / Arctic theme switch, saved in LocalStorage
- Complete RU / EN interface switch
- Task create, edit, delete, complete, priority, due date and duration
- Search and filters
- Gemini-powered schedule generation (when configured)
- Explicitly labelled DEMO MODE fallback
- Schedule copy and TXT export
- Saved plan history
- Monthly calendar with task markers
- Statistics calculated from actual task data
- Manual QA checklist
- Responsive desktop and mobile layout

## Data storage
Tasks, theme, language, test marks and plan history are stored in the browser's LocalStorage. They are not synchronized across devices. Clearing browser data can remove them.

## Limitations
- AI can misestimate task duration or priority.
- Real AI planning requires internet access and a valid Gemini API key.
- LocalStorage is local to one browser and can be cleared.
- The calendar is an in-app calendar, not Google Calendar synchronization.
- This educational prototype is not a professional task-management or notification service.
- Public deployment requires a server, environment-secret management, request validation, rate limiting and appropriate privacy controls.

## Quality checks
The Testing section contains eight manual scenarios. A test is not marked PASS automatically. Run each scenario and mark it as verified only after observing the expected result. For the AI tests, configure a valid server-side Gemini key first.
